### 一、模型架构变更

#### 1.1 解码器瘦身
| 项目 | 0601 原版 | 0610 final |
|------|----------|------------|
| 转置卷积层数 | 7 层 | **6 层** |
| 输出形状 | `[B,4,2048]` | `[B,8,1024]` |
| 中间维度膨胀比 | 256→8192 (32×) | 256→8192→**4096 (16×)** |

**理由**: 原版从 256 维膨胀到 8192 维再缩到 1246 维，中间沙漏太宽，1024 维对 1246 点输出更匹配，降低过拟合。

#### 1.2 任务头渐进投影
| 项目 | 0601 | 0610 final |
|------|------|------------|
| freq_proj | `Linear(2048, 1246)` | `Linear(1024,512)` + `Linear(512,1246)` |
| 参数量/head | ~255 万 | ~117 万 (**↓54%**) |

**理由**: 52 个独立 head × 平均 21 条训练数据/head，直接大矩阵投影极易过拟合。

#### 1.3 BatchNorm → InstanceNorm
```
TransposeConvBlock: BatchNorm1d → InstanceNorm1d
```
**理由**: batch_size=8 下 BN 统计量噪声大（每个通道仅 8 个样本）。IN 逐样本独立归一化，不受 batch 影响，在小批量生成模型中为行业标准做法。

#### 1.4 频谱频率范围
```
2501 点 (0~10000Hz @4Hz) → 1246 点 (20~5000Hz @4Hz)
切片: parsed[5:1251]
```

### 二、损失函数重构 (V2)

#### 2.1 移除的损失项

| 移除项 | 原因 |
|--------|------|
| **Cosine 相似度** (原 weight=1.5) | dB 值全正 (20~80dB)，所有向量方向高度相似，cos 值 0.95~1.0，梯度≈0 |
| **LogMSE** (原 weight=1.5) | dB = 20·log10(P/Pref) 已是对数域；log(dB) = log(log(P)) 双重对数无物理意义 |
| **OASPL** (原 weight=1.0) | OASPL 从频谱派生，MSE 最小化后 OASPL 自然接近；单独损失项冗余且产生梯度冲突 |

#### 2.2 新增损失项

| 新增项 | weight | 公式 | 作用 |
|--------|--------|------|------|
| **线性峰值 MSE** | 2.0 | `MSE(10^(dB/20), 10^(target/20))` | dB→声压比，自动侧重高峰值（60dB处误差≈100×于20dB处） |

#### 2.3 调整的损失项

| 调整项 | 0601 | 0610 final | 理由 |
|--------|------|------------|------|
| dB-MSE | 7.39 | **5.0** | 降低以避免 mse 主导 |
| Sobolev 梯度 | 2.72 | **3.0** | 增强频谱平滑约束 |

#### 2.4 最终损失组成

```
Total = 5.0 × dB-MSE + 2.0 × LinearPeak + 3.0 × Sobolev
```

### 三、训练策略优化

#### 3.1 EMA (指数移动平均)
```python
ema_model = deepcopy(model)  # 平滑模型, 不参与训练
ema_p = 0.999 × ema_p + 0.001 × model_p  # 每个 step 更新
```
- 验证用 EMA 模型 (泛化能力更强)
- 保存的是 EMA 权重
- **预期降低验证损失 2~5%**

#### 3.2 LR warmup
```python
前 5 epoch: lr 从 0 线性升至 3e-4
```
**理由**: AdamW 初始动量未建立，直接 3e-4 的 lr 会导致早期梯度震荡。

#### 3.3 调度器调整

| 参数 | 0601 | 0610 final |
|------|------|------------|
| `T_0` | 20 | **150** |
| 首周期步数 | ~2,700 | **~16,200** |
| **LR warmup** | 无 | **前5 epoch** |

#### 3.4 DataLoader 优化
```python
num_workers=2, persistent_workers=True
```
- 加速 CPU 端数据增强
- 减少 GPU 等待时间

#### 3.5 超参数调整

| 参数 | 0601 | 0610 final | 理由 |
|------|------|------------|------|
| lr | 5e-4 | **3e-4** | 小样本更稳定 |
| weight_decay | 5e-3 | **1e-3** | 避免过度压缩参数 |
| batch_size | 8 | 8 | 不变 |
| epochs | 50000 | 50000 | 不变 |
