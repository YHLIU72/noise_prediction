========================================
              PI-MBCN 模型开发日志
========================================

【版本1.0】五一之前的模型结构
----------------------------------------
- 编码器：2层全连接 (3→64→128)
- 解码器：3层转置卷积 (10→20→40→2501)
- 输出头：简单线性层
- Alpha：静态参数
- 特点：基础结构，参数较少

【版本2.0】2026年5月4日 - 增加参数量
----------------------------------------

一、编码器增强
- 层数：2层 → 3层
- 维度：64→128 → 128→256→256
- 新增BatchNorm和Dropout

二、解码器增强（关键改进）
- 策略：渐进式上采样，避免跨度过大
- 旧结构：16 → 32 → 64 → 128 → 2501（最后跨度20倍）
- 新结构：16 → 32 → 64 → 128 → 256 → 512 → 1024 → 2501（渐进式）
- 通道数：256→256→192→128→96→64→32→1
- 新增输出平滑层（1x3卷积）

三、输出头增强
- OASPL头：加深至3层 (256→128→1)
- 倍频程头：加深至3层 (256→128→28)
- Alpha头：加深至3层，动态预测

【版本3.0】2026年5月6日 - 简化模型结构
----------------------------------------

一、移除冗余预测头
- 移除：OASPL预测头（通过频谱计算OASPL代理）
- 移除：三分之一倍频程预测头
- 保留：频谱预测头、Alpha预测头

二、非线性层替代插值
- 原方案：F.interpolate线性插值从2048→2501
- 新方案：多层全连接网络 (2048→1024→1536→2048→2501)
- 优点：学习更复杂的映射关系，增强表达能力

三、损失函数简化
- 移除：loss_mse_oaspl（OASPL损失）
- 移除：loss_mse_octave（倍频程损失）
- 保留：loss_mse_spec（频谱MSE）
- 保留：loss_cosine_spec（频谱余弦相似度）
- 保留：loss_physics（物理约束损失）
- OASPL代理：通过频谱能量计算，用于物理约束

四、模型输出变更
- 原输出：(oaspl, octave_spectrum, spectrum, alpha)
- 新输出：(spectrum, alpha)

五、预期效果
- 简化模型结构，减少参数量
- 专注于频谱预测核心任务
- 通过频谱计算OASPL保持物理约束有效性
- 非线性映射提升频谱细节拟合能力

【版本4.0】2026年5月9日 - 深度优化与训练策略升级
----------------------------------------

一、编码器增强
- 隐藏层维度：256 → 2048
- 结构：3层全连接 (3→512→1024→2048)
- 每层添加BatchNorm、GELU、Dropout(0.1)

二、解码器重构（关键改进）
- 新增TransposeConvBlock：转置卷积+BN+GELU+残差连接
- 通道数策略：512→512→256→128→64→32→16→8
- 序列长度：16→32→64→128→256→512→1024→2048
- 新增精炼卷积层和输出精炼层（5x5+3x3卷积）
- 维度调整：两级线性层 (2048→2274→2501)
- 优点：残差连接缓解梯度消失，提升深层网络训练稳定性

三、损失函数进一步简化
- 移除：物理约束损失（loss_physics）
- 移除：learned_alpha相关所有模块
- 保留：loss_mse_spec（频谱MSE）
- 保留：loss_cosine_spec（频谱余弦相似度）
- 保留：合成OASPL损失（从频谱计算）
- OASPL计算添加epsilon=1e-10防止数值不稳定

四、模型输出变更
- 原输出：(spectrum, alpha)
- 新输出：(spectrum)

五、训练策略优化
- batch_size：8 → 4（适配更大模型）
- learning_rate：1e-3 → 5e-4（降低学习率）
- epochs：200 → 300（增加训练轮数）
- weight_decay：5e-3 → 1e-4（调整正则化强度）
- 学习率调度器：CosineAnnealingLR → CosineAnnealingWarmRestarts

六、预期效果
- 更深的网络结构提升特征表达能力
- 残差连接确保梯度稳定传递
- 精炼层提升频谱输出质量
- 优化的训练策略适配大模型训练

【版本5.0】2026年5月14日 - 核心优化与断点续训
----------------------------------------

一、前向传播批处理优化（关键改进）
- 文件：PIMBCN_net_1_1_1_1.py
- 问题：原代码使用逐样本循环，破坏GPU并行计算
- 优化：采用动态掩码并行路由策略
- 实现：将同一分支的样本组合成子批次统一处理
- 效果：训练速度提升成百上千倍

二、频谱维度调整优化
- 文件：PIMBCN_net_1_1_1_1.py
- 问题：全连接层破坏频率相邻相关性
- 优化：使用F.interpolate线性插值替代全连接层
- 优点：保留物理相关性，不增加参数

三、OASPL计算数值稳定性优化
- 文件：PIMBCN_net_1_1_1_1.py
- 问题：指数函数导致数值溢出和梯度爆炸
- 优化：采用Log-Sum-Exp技巧
- 公式：OASPL = max_L + 10 * log10(sum(10^((L - max_L)/10)))

四、断点续训功能
- 文件：PIMBCN_train_1_1_1_1.py
- 新增命令行参数：--resume 检查点路径
- 保存内容：模型权重、优化器状态、调度器状态、epoch、最佳损失
- 兼容性：支持旧格式检查点（仅模型权重）
- 使用方式：
  python PIMBCN_train_1_1_1_1.py --resume runs/xxx/models/best_model.pth

五、绘图脚本优化
- 文件：demo.py
- 图片宽度：14cm → 8cm
- 分辨率：600dpi（论文插图标准）
- 字体：Times New Roman
- 支持绘制：OASPL曲线、1/3倍频程频谱、窄带频谱
