================================================================================
  PIMBCN (Physics-Informed Multi-Branch Convolutional Network) 模型版本演进日志
================================================================================

项目概述：基于物理信息引导的多分支卷积网络，用于气动噪声频谱预测。
输入为 3 个无量纲工况参数（对应 csv 列 4,5,6），输出为 2501 点频域声压级频谱。
采用分 mode（4 类）× type（13 类）= 52 个分支的多任务学习架构。
数据来源：csvdata333，训练/验证 = 80/20 划分。

================================================================================
  V1 (Base) — 初始多分支物理约束模型
  网络: 2026-05-06 14:44 / 训练: 2026-05-06 15:05
================================================================================
文件：
  PIMBCN_net.py           网络定义
  PIMBCN_train.py         训练脚本

【网络结构】
Encoder（共享）: 3→128→256→256 (hidden_dim=256)，每层 BN+GELU+Dropout(0.1)

Decoder（52个独立分支，每个 mode-type 各有完整解码器）：
  - fc_expand: 256→512→4096 (=256ch × 16seq)
  - 7层 TransposeConv1d 渐进式上采样: 16→32→64→128→256→512→1024→2048
  - 通道递减: 256→256→192→128→96→64→32→16
  - 维度调整: F.interpolate(2048→2501) + Conv1d(1→1, k=3) 后处理
  - OASPL 预测头: 256→256→128→1 (GELU+Dropout 两层隐藏)
  - 倍频程预测头: 256→256→128→28
  - Alpha 预测头: 256→128→64→1 → 输出 = 0 + 8×sigmoid(raw) [范围 0~8]

52 个分支 = 4 modes × 13 types，每个分支实例完整的 SpectrumDecoder1DCNN

【损失函数 physics_informed_loss_fn】
  - MSE(频谱)
  - 10×Cosine Similarity(频谱)
  - 1×MSE(OASPL)
  - 20×MSE(倍频程)
  - λ_phy × MSE(∂OASPL_pred/∂RPM, 10·α/(ln10·RPM_real))

物理约束：用 torch.autograd.grad 计算预测 OASPL 对 RPM 的梯度，与
理论公式 grad = 10·α/(ln10·RPM) 做 MSE 匹配。

【训练配置】
  优化器: AdamW(lr=1e-3, weight_decay=1e-4)
  调度器: StepLR(step=30, gamma=0.5)
  轮数: 200, batch_size: 8, λ_phy: 2.0

特点：首次建立完整的 4 输出头 + 物理约束 + 52 分支框架。

  - 维度调整: F.interpolate → nn.Linear(2048→2501)+GELU+Dropout+Linear(2501→2501)

  - Cosine 权重: 10→200, MSE(OASPL): 1→20, MSE(倍频程): 20→50

  - weight_decay: 1e-4→5e-3（加强 L2 正则化）

  - 新增 refine_conv + refine_bn 精炼层

  lr: 1e-3→5e-4, weight_decay: 5e-3→1e-4

动机：alpha 学习不稳定，不同工况理想值差异大；残差连接改善深层网络梯度；
纯数据驱动+OASPL 辅助约束比物理梯度损失更稳定。


================================================================================
  V1.1.1.1.1 — Hard Parameter Sharing 多任务学习 (MTL) 架构
  网络: 2026-05-11 12:32 / 训练: 2026-05-11 21:16
================================================================================
文件：
  PIMBCN_net_1_1_1_1.py   网络定义
  PIMBCN_train_1_1_1_1.py 训练脚本

【相比 V1.1.1.1 的网络改动（架构范式转变）】
从 52 套独立解码器 → 共享主干 + 52 个轻量级任务头:

  SharedDecoderBody（全局共享）:
    - 替代 52 套独立解码器的上采样部分
    - fc_expand + 7层 TransposeConvBlock
    - 输出: [B, 8, 2048] 通用声学特征图

  LightweightTaskHead（52个独立但极轻量）:
    - refine_conv(8→8,k3) + BN + GELU
    - final_conv(8→1,k1)
    - F.interpolate(2048→2501, mode='linear') ← 保留声学频带相邻归纳偏置
    - output_refine: Conv1d(1,1,k5)+GELU+Conv1d(1,1,k3)

  动态掩码路由 (Dynamic Masked Routing):
    - combo_idx = mode_idx × num_types + type_idx
    - 按 combo 分组，同分支样本批量前向
    - 共享特征的梯度在 SharedDecoderBody 汇合

  数值稳定性: safe_oaspl() 使用 Log-Sum-Exp 防梯度爆炸
    max_L = max(spectrum/10), sum_exp = exp(spectrum/10 - max_L)
    OASPL = 10·(log10(sum_exp) + max_L)

【损失改动】
  OASPL 损失权重: 20→1.0（靠 safe_oaspl 数值稳定后不需大权重）

【训练改动】
  batch_size: 4→16（架构高效，显存降低）
  epochs: 300→1500（共享主干需要更多迭代）
  解耦学习率: 共享模块 lr=1e-4 / 任务头 lr=5e-4
  新增梯度裁剪: clip_grad_norm_(max_norm=1.0)
  Tensorboard 增加学习率监控

动机：V1.1.1.1 的 52 个独立解码器参数量巨大，极易过拟合且显存不足；
共享主干让 52 个任务共同训练同一套物理特征提取器，泛化能力显著提升；
动态路由实现批量并行，训练速度提升数百倍。

  V514 — SE 通道注意力 + 残差任务头 + 自适应损失权重（最终版）
  网络: 2026-05-14 16:05 / 训练: 2026-05-14 16:06
================================================================================
文件：
  PIMBCN_net514.py         网络定义（含自适应损失模块）
  PIMBCN_train514.py       训练脚本

【相比 V1.1.1.1.1 的网络改动】

1. SEBlock1D 通道注意力（新增组件）:
   - 位置: SharedDecoderBody 末端（转置卷积后）
   - 结构: AdaptiveAvgPool1d(1) → Linear(C→C/4) → ReLU → Linear(C/4→C) → Sigmoid
   - 功能: 自适应学习 8 个通道的重要性权重，捕捉不同频带衰减特性
   - reduction=2, 使用 ReLU（非 GELU）

2. LightweightTaskHead 升级为残差瓶颈结构:
   - 瓶颈: Conv1d(8→16,k3) + BN + GELU + Conv1d(16→8,k3) + BN
   - 残差: out + identity（缓解梯度消失）
   - 插值: F.interpolate(2048→2501)
   - 平滑: Conv1d(1,1,k5)+GELU+Conv1d(1,1,k3)（消除插值伪影）

3. PhysicsLossWrapper — 同方差不确定性自适应损失权重（核心创新）:
   - 3 个可学习参数 log_vars（对应 MSE / Cosine / OASPL）
   - 权重公式: w_i = exp(-log_var_i)
   - 损失公式: Loss = Σ( w_i × loss_i + log_var_i )
   - 原理: Homoscedastic Uncertainty（同方差不确定性）
   - 自动学习三个损失项的最优权重比例，避免人工调参
   - safe_oaspl 计算移入 PhysicsLossWrapper

【训练改动】
  共享主干学习率: 1e-4→5e-4（与头相同）
  轮数: 1500→7500（大幅增加）
  优化器参数组新增 loss_wrapper.parameters()
  checkpoint 保存 loss_wrapper_state_dict
  Tensorboard 新增: MSE_Weight, Cosine_Weight, OASPL_Weight 动态监控

动机：手动权重(200×cosine, 1×OASPL)未必最优；同方差不确定性提供理论保证
的自动权重学习；SE 注意力帮助主干区分频带物理重要性；残差头增强峰值拟合。

  V0521 — 训练性能全面优化版（模型结构不变，训练速度 10-20x 提升）
  数据: 2026-05-21 / 网络: 2026-05-21 / 训练: 2026-05-21

文件：

  PIMBCN_net0521.py       网络定义（优化版，结构同 V514）
  PIMBCN_train0521.py     训练脚本（优化版）

【优化背景】
V514 在另一台电脑上训练速度极慢，经分析有三个层级的性能瓶颈：
  1. 数据管道：每个 __getitem__ 调用执行 6 次 pandas iloc + 2 次 ast.literal_eval
  2. 模型：TransposeConvBlock 中逐层无效条件判断 + Python for 循环逐 combo 处理
  3. 训练：未启用多进程数据加载、混合精度、模型编译

【数据管道优化】PIMBCN_data_0521.py
  - __init__ 中新增 _preparse_all_columns():
    * 一次性 ast.literal_eval 解析所有 octave 和 spectrum 列的字符串
    * spectrum 截断/补齐到 2501 点
    * 全部列预转换为 numpy 数组（inputs/types/modes/oaspl/octave/spectrum）
  - __getitem__ 简化为纯 numpy 索引 + torch.from_numpy:
    * 零次 pandas iloc 调用
    * 零次 ast.literal_eval 调用
    * 零次列表截断/补齐
  - 归一化参数也存为 float32
  - 预期加速: 5-10x

【网络模型优化】PIMBCN_net0521.py
  - TransposeConvBlock 重构:
    * 移除 use_residual 标志（本配置永远启用）
    * 移除 if in_channels != out_channels 条件（本配置永远不匹配）
    * 移除 F.interpolate 长度对齐（kernel=4,stride=2,padding=1 精确翻倍）
    * forward 从 11 行减到 3 行，消除每层 2 次分支判断
  - 代码注释精简
  - 网络结构、参数量、计算逻辑与 V514 完全一致
  - 预期加速: 5-10%（边际优化）

【训练脚本优化】PIMBCN_train0521.py
  - AMP 混合精度训练:
    * torch.cuda.amp.GradScaler + autocast
    * 梯度裁剪适配 AMP: scaler.unscale_() 后再 clip
    * 预期加速: 1.5-2x，显存减半
  - torch.compile():
    * 对 for 循环中多次小 kernel launch 的模型效果显著
    * 预期加速: 1.3-1.5x
  - DataLoader 多进程:
    * num_workers=4, pin_memory=True
    * persistent_workers=True（避免每 epoch 重启 worker）
    * 数据传输 .to(device, non_blocking=True)
    * 预期加速: 1.5-2x
  - 其余配置与 V514 一致: 7500 epochs, bs=16, CosineAnnealingWarmRestarts, 解耦学习率

【注意事项】
  - 网络结构与 V514 等价，checkpoint 可互相加载（但 torch.compile 需要先禁用）
  - torch.compile 首次运行会有一段编译时间，后续 epoch 正常
  - 如果 PyTorch 版本 < 2.0，torch.compile 会自动跳过
  - 如果显存不足，可将 batch_size 从 16 降回 8

【综合预期效果】
  数据管道重构 (5-10x) × 多进程加载 (1.5-2x) × AMP (1.5-2x) × compile (1.3-1.5x)
  ≈ 总体 10-20x 训练加速

================================================================================
  V0610 — 损失函数 V2 重构版
  数据: 2026-06-10 / 网络: 2026-06-10 / 训练: 2026-06-10
================================================================================
文件：
  PIMBCN_data_0610_lossV2.py   数据加载（损失V2配套版）
  PIMBCN_net0610_lossV2.py     网络定义（损失V2重构版）
  PIMBCN_train0610_lossV2.py   训练脚本（损失V2重构版）

【损失函数重构】
  - 移除 Cosine 相似度: 全正 dB 值下退化为常数，梯度≈0，无监督意义
  - 移除 LogMSE: dB 已是对数域，双重对数无物理意义
  - 移除 OASPL 损失: 与 MSE 高度冗余，不提供新监督信号
  - 新增线性域峰值 MSE: dB→声压比转换，自动侧重高峰值区域
  - 保留 dB-MSE (核心) + Sobolev 梯度 (平滑约束)

【新损失组成】
  Loss = 5.0×MSE + 2.0×LinearPeakMSE + 3.0×Sobolev

【训练配置】
  - lr=3e-4, T_0=200, wd=1e-3, batch=8, freq_bins=1246
  - 数据增强: augment=True

【动机】
  原始损失组合存在多个问题：
  1. Cosine 相似度在全正 dB 值分布下接近常数，梯度消失
  2. OASPL 损失与频谱 MSE 高度线性相关，提供冗余监督
  3. 峰值区域预测误差对听觉感知影响更大，需额外约束

【相对 V0610_lossV2 的增量优化】
  [模型层]
  - TransposeConv: BatchNorm1d → InstanceNorm1d
    理由: batch_size=8 下 BN 统计量噪声大, IN 逐样本归一化不依赖 batch
  [训练策略]
  - EMA (指数移动平均, decay=0.999): 每 step 平滑权重, 验证/保存均用 EMA 模型
  - LR warmup: 前 5 epoch 线性爬升 (0→3e-4), 避免早期梯度震荡
  - T_0: 200→150, 首周期略短更早精细收敛
  - DataLoader: num_workers=2, persistent_workers=True (加速数据加载)
  [数据]
  - OASPL 约束自洽 (增强时基于20~5000Hz频谱自算OASPL)
  - 验证集共享 numpy 数组 (避免重复加载 CSV)
  [架构]
  - 解码器去最后一层 deconv: [B,4,2048]→[B,8,1024], 中间维度减半
  - freq_proj: Linear(2048,1246)→Linear(1024,512)+Linear(512,1246), 渐进投影

【预期效果】
  - 模型总参数: ~1.33亿→~0.61亿 (↓54%), 每个 head 参数 ~255万→~117万
  - EMA 预期降低验证损失 2~5%
  - LinearPeakMSE 自动侧重峰值区域精度
  - InstanceNorm 消除小 batch BN 统计量偏差

  [策略1 — 梯度累积] accum_steps=2, 等效 batch=16
    理由: batch=8 梯度噪声大, 累积2步等效16样本/更新, 收敛更稳定
  [策略2 — 多分辨率损失] 原生 + 2×下采样(×0.3) + 4×下采样(×0.1)
    理由: 粗尺度损失引导模型先学宽带趋势, 再学细节, 课程学习效应
  [策略3 — Mode/Type 嵌入] 解码器输入端注入可学习工况嵌入
    理由: 解码器不再"盲生成", 16维嵌入告知当前工况, 各组合差异化
  [辅助 — LayerNorm 修正] [16,1024]→1024 (逐通道归一化, 不过度压缩)
  [辅助 — 傅里叶 scale] 3.0→1.0 (温和特征映射, 适配平滑物理函数)
